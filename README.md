# Tic Tac Toe Game

This is a simple implementation of the classic Tic Tac Toe game developed using HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: The game is styled using CSS and is responsive to different screen sizes.
- **Interactive Gameplay**: Players can click on the grid to place their marks (X or O).
- **Win Detection**: The game detects when a player has won and displays a congratulatory message.
- **Tie Detection**: The game detects when the match is tied and prompts the players to try again.
- **Reset Functionality**: Players can reset the game at any time to start a new match.

## Technologies Used

- **HTML**: For the structure of the game.
- **CSS**: For styling the game, including hover effects and responsive design.
- **JavaScript**: For the game logic, including turn alternation, win detection, and reset functionality.
